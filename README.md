# root-combinations-py
Python script to generate a CSV with all possible combinations of factions for the Root board game. https://ledergames.com/products/root-a-game-of-woodland-might-and-right

## The List

Output of the script (as a CSV file) is [here](https://github.com/AmasaDelano/root-combinations-py/blob/main/combinations.csv).

## Notation:

- **Adv.** means only for adventurous groups (according to the Law of Root)
- **Adv. w/H.** means only for adventurous groups that include hirelings (according to the Law of Root)

## Searching

To search and filter the combinations, download it and open it in a program like [LibreOffice Calc](https://www.libreoffice.org/discover/calc/) or [Visual Studio Code](https://code.visualstudio.com/) with the [Excel Viewer extension](https://github.com/jjuback/gc-excelviewer).

In LibreOffice Calc, select all cells (Ctrl+A or Cmd+A) and click the AutoFilter button in the toolbar to turn on easy filtering.
